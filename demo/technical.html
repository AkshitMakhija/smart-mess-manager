Crowd Estimation using Camera

The system uses cameras installed at the mess entrance to monitor the number of students entering and exiting. Computer vision algorithms analyze the video feed in real-time to count people. This data is processed to determine the current crowd level (Low, Medium, or High) which is then displayed on the student dashboard.

The camera captures images at regular intervals, and image processing techniques identify and count individuals. This count is updated continuously to provide accurate real-time information to students.

Basic Predictive Analysis using Historical Data

The system collects data about crowd patterns over time - recording how many students visit the mess at different hours of the day and days of the week. This historical data is stored in a database.

Using simple statistical methods, the system analyzes past patterns to predict future rush times. For example, if data shows that 1:00 PM typically has the highest crowd on weekdays, the system predicts this as a peak hour. These predictions help students plan their meal times better.

Backend Server handling Data

A backend server acts as the central component that receives data from various sources (cameras, mobile app, web interface) and processes it. The server stores all information in a database including crowd counts, student feedback, food voting data, and menu information.

When students access the dashboard, their devices send requests to this server. The server retrieves the latest data from the database and sends it back to be displayed. Similarly, when students submit feedback or vote, the data is sent to the server and stored for administrators to review.

Mobile App Integration Concept

A mobile application provides students with convenient access to mess information on their smartphones. The app connects to the same backend server as the web dashboard, allowing students to check crowd levels, view menus, and submit feedback while on the go.

The mobile app can also send push notifications to alert students about peak hours or menu changes. This integration ensures that students have access to real-time information regardless of whether they use a computer or mobile device.
